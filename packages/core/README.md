# @productops-mcp/core

Shared schemas, tool runtime, errors, policy and logging for the [productops-mcp](https://github.com/EugeneNeverov/productops-mcp) servers. You probably want [`@productops-mcp/prioritization`](https://www.npmjs.com/package/@productops-mcp/prioritization) or [`@productops-mcp/jira`](https://www.npmjs.com/package/@productops-mcp/jira) instead.
